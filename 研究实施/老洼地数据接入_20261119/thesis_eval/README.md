# 老洼地 48 题论文评测协议（v1）

本基准回答三个问题。在同题、同资料和同一 DeepSeek 模型下，领域智能体能否提高全任务正确率和拒答质量？逐个移除条件化混合检索、GSSC、pandapower 和数值核验与 Reflection 后，哪些题受影响？质量变化伴随多少 Token 和端到端时延？

[冻结题面与输出字段](cases.json) · [答案键与引用](gold.json) · [本地实验数据](results/offline_probes.json) · [本地实验结果](results/本地实验结果.md)

## 样本与标注

每层 8 题，共 48 个计分情节、56 个作答轮次。单点、统计题覆盖七份运行日报。资料范围和九份原件 SHA-256 固定在题集中。标准条款只作适用性参考。回放工具若被调用，其出处仍追到七份日报。

| 层次 | 题号 | 任务与可复核目标 |
| --- | --- | --- |
| 单点溯源 | S01–S08 | 读取指定时点的电压、电流、有功、功率因数。逐项核对单位、符号和原表坐标。 |
| 多柜时空统计 | M01–M08 | 多柜同日极值、均值、整点矩形积分及同期功率差。均值和积分以极值单元格作为最小引用要求，同时按题面声明整日窗口。 |
| 跨站与缺证 | N01–N08 | 井下柜实测缺档、归档前后日期、设备额定值、开关状态及无来源输入。部分题同时要求给出可确认的图示上游。 |
| 多假设故障归因 | D01–D08 | 用同期柜读数检查反向有功、零读数、扫描时序与量测符号。判读优先核查方向、所缺证据和可否定案。 |
| 潮流与 N‑1 | P01–P08 | 基准、分接头灵敏度、1009 退出等值情景、1010 补偿灵敏度、设备与转供缺证。 |
| 人工补证 | H01–H08 | 两轮保留同一原表事实，用演练参数包触发条件满足、越限、仍缺证或拒收。含热条件满足但联络闭锁的反例。 |

单点与统计答案独立从 SQLite 读原始导入行，用显式聚合重算；出处由原表文件、工作表和坐标组成。仿真六题的数值参考调用冻结配置下的 pandapower 求解器，实测边界来自独立查表。这部分检验求解与回执一致性。等值参数、假定开关、现场动作和实际故障效果均需要矿方资料复核。补证中的额定值、降容和工作状态是实验输入，只有原归档峰值属于现场数据。

H01–H08 先问实测和条件结论，再提交统一格式的假定补证包。各方法拿到相同的包与自己上一轮的发布答案。领域组可调用原有补证复算函数，并保留父子版本。两个时点的输出字段契约固定，所有补证后题面都提供同一个可选负载率字段。未覆盖实际值班人员的采集、定时参与或多轮补证耗时。

归因标签由研究者按“观察—替代解释—所缺证据—是否定案”标注。正式提交论文前，由两名未参与实现的复核者独立查阅原件和判据，隐藏方法名、运行顺序与模型原稿，复核逐题判定、出处集、可接受替代答案和归因排序。类别报告一致率与 Cohen’s κ，数值及引用分别记录分歧与裁决。对题面或答案键的实质修订须升级版本并重跑全部方法。v1 尚无双人复核记录。旧 6、12、36 题结果用于开发回归。v1 中仍有共用事件和同源时段，整套题集按单站单周回放解释。

## 方法与四项消融

| 条件 | 输入及工具 |
| --- | --- |
| Vanilla LLM / Prompt-only | 直接附题面显式日期和柜号对应的日报整点表、对应连线及必要归档标准摘要。用字面日期/柜号拼表，单次调用，无相关性检索工具。 |
| Standard RAG | 同一材料来源，按柜号和四小时窗切分日报，图示台账逐边、规程按条切分。固定 BM25 top‑8 给单次生成。 |
| Standard ReAct Agent | 基于相同材料，模型迭代调用 BM25 和四个基础点查、日统计、拓扑、回放工具。 |
| Ours（Laowadi Domain Agent） | ReAct 风格只读工具环，复用领域复合查询、条件化混合检索、GSSC、pandapower、补证复算与原表数值核验。标准化主张进入共同计分出口，失败反馈给模型重选或修正。 |
| 去条件化混合 RAG | 用同一 BM25 替换条件化混合检索和领域规程检索，保留其他领域工具。该消融估计检索、领域卡与适用性守卫的合并贡献。 |
| 去 GSSC | 原样传工具回执，核验仍使用相同的原始回执。 |
| 去 pandapower | 隐藏并拒绝调用交流潮流工具。保留解析近似、参数复算和其他领域查询。 |
| 去双层数值核验与 Reflection | 使用相同的工具、题面、输出字段与模型首稿协议，按解析后的主张直接计分，跳过引用与当前回执检查、数值/单位对齐及核验反馈重试。 |

这里的 Ours 是专用评测入口，和基线共用结构化字段与同一评分器。它复用生产计算与核验函数，派生量核验绑定工具回执路径。生产入口的自由文本诊断、独立语义审查、工作台编排和发布耗时需另外测量，不能由这个表外推。文献用于界定方法类别。此处的 BM25 和工具轮转是针对本项目的实现。[Lewis 等，RAG](https://arxiv.org/abs/2005.11401) · [Yao 等，ReAct](https://arxiv.org/abs/2210.03629)

所有条件锁定 `deepseek-v4-pro`、非流式、相同输出字段、相同资料版本，显式请求关闭推理模式。工具组每轮最多 5 次模型调用、10 次执行、每次生成上限 1024 Token。单次生成基线使用同一个单次生成上限。配置不固定服务端采样或模型权重版本。用固定实验次序种子洗牌并配对重复，保存服务端报告的模型名、用量、返回状态和实测耗时。当前是空白的模型矩阵，计划首轮 384 题次、448 作答轮，另作共三轮重复测量时总计 1,152 题次、1,344 作答轮。并发数、冷启动、缓存命中、请求重试和上下文长度均影响时延，正式比较按同机、同并发和同配置配对。

## 指标和对照分析

| 指标 | 计分方式 |
| --- | --- |
| 整题正确率 | 终态、所有目标字段、单位和引用均匹配。双轮题必须两轮均正确。分母是计划题次，协议或接口失败单列。 |
| 数值幻觉率 | 不合格数值主张 ÷ 所有发布的数值主张。不合格包括错数、错单位、引用无法共同支撑、未要求或重复出现的数值。附宽口径错数率与数值正确覆盖率，防止少报数值获得低幻觉率。 |
| Citation F1 | 对「题轮次、主张字段、引用定位符」做 micro-F1。值或单位错误时，即使碰巧引用正确坐标也无 TP。金标准使用题面约定的最小引用集合。 |
| Abstention Accuracy | 有可解析结果的轮次中，将 `insufficient` 当作拒答，统计缺证/可答二元判定准确率。同时报告缺证召回、误拒答率、解析覆盖率和三态整题分。 |
| Token | 汇总服务端 usage 的输入、输出、总 Token。用量缺失或失败重试的轮次单列覆盖率。 |
| 时延 | 单轮墙钟耗时，包含检索、调用、重试、工具执行与终审。报告 P50/P95、协议或接口失败数。HITL 等待用户的现实时间未计入。 |

四项消融分别报告 Ours 减消融组的配对差及 95% 簇 bootstrap 区间。按同源日期或补证机制保持成对，复测轮次及双轮题随题一起抽样。主要效应看整题正确率，其余指标用于定位错误或成本。分层结果和相关性用于描述；现有簇数不足以强推跨矿泛化。多项比较以效应量和区间呈现，若论文使用显著性检验，预先锁定主假设并做 Holm 校正。引用判分与独立人工审阅保留逐题分歧。

错误可从逐字段记录和回执重查，包括原表错位、正确单元格配错值、单位错、同值但日期或柜号错、虚假现场定案、把仿真当实测、错误接受补证和无证据硬答。接口失败、轮数超限与终审撤回有单独状态。

## 复现

在 `研究实施/老洼地数据接入_20261119` 下执行。现场数据留在当前归档库，以下本地命令无模型请求。

```sh
../.venv-power/bin/python -B -m thesis_eval.probe --output thesis_eval/results
```

`freeze.py` 仅用于复验或发布新题集。实验请求由 `cases.json` 提供题面，`gold.json` 用于离线计分。目录中的哈希固定脚本、题集、答案和归档范围。已有模型配置继续从原本地文件读取。

下列实跑尚待明确的外发授权。请求会向已配置的模型端点传输题目、归档文本/表格或只读回执，以及演练补证内容。Prompt-only 按题附日报切片，跨周题只含题面所在柜号。结果路径下按重复轮次、方法和题号写入，已完成项可恢复跳过。若代码或运行预算改变，使用新目录保留先前记录。

```sh
../.venv-power/bin/python -B -m thesis_eval.run --output local/thesis_eval_v1/records --jobs 4 --repeat 3
../.venv-power/bin/python -B -m thesis_eval.score local/thesis_eval_v1/records
```

`results.md` 给论文主表，`by_layer.csv` 给六层结果，`score.json` 保存配对区间、逐题证据和分母。指定 `--repeat 1` 可先核对唯一一轮并运行端到端试验。实际运行目录含归档派生证据，沿用项目的本地数据存放方式。
