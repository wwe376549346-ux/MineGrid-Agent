# 雷雨大风天气 35/10 kV 防雷与过压特巡 SOP

1. 扫描 35 kV 进线（`303` / `306`）与 10 kV I/II 段（`1005` / `1006`）电压极值与越限整点分布，核查避雷器及过压告警风险。
2. 运行 `pandapower` 交流潮流评估 2# 主变分接头留足调压裕度的最优挡位。
3. 核查高波动负荷馈线与关键排水/通风回路供电连续性，提前准备好防停电应急预案与两票草案。
4. 如遇电压持续高于 10.70 kV，须先经人工复核现场挡位与调度令后再履行调压审批。
