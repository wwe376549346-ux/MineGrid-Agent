# 主通风机倒机前双回路供电核查 SOP

1. 核查 35 kV 两回进线（`303` / `306`）与 10 kV 两段母线（`1005` / `1006`）当前运行电压与功率守恒状态，确认无单进线隐性过载。
2. 核查主干下井双回路（`1009` / `1010`）实时负荷、功率因数及 N-1 断线转供裕度。
3. 依据《煤矿安全规程（2025）》第四百七十二条与 GB/T 50417-2017 3.0.3，确认主通风机双回路分别取自不同母线段且闭锁正常。
4. 任何倒机操作前必须经值班长与矿调度室确认并履行双人监护审批。
